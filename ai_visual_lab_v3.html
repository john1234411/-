개념 설명

BFS(너비 우선 탐색)은 시작점에서 가까운 노드부터 방문합니다. 먼저 들어온 노드를 먼저 꺼내는 큐(FIFO)를 사용합니다.

DFS(깊이 우선 탐색)은 한 경로를 최대한 깊게 탐색한 뒤 막히면 이전 갈림길로 돌아옵니다. 스택(LIFO) 또는 재귀 호출을 사용합니다.

시간 복잡도는 인접 리스트를 사용할 때 두 방식 모두 O(V+E)입니다. V는 정점 수, E는 간선 수입니다. BFS는 간선 가중치가 동일한 그래프에서 최단 간선 경로를 찾을 수 있지만, DFS는 일반적으로 최단 경로를 보장하지 않습니다.

KNN 알고리즘의 핵심

KNN(K-Nearest Neighbors)은 새 데이터와 학습 데이터 사이의 거리를 모두 계산한 뒤, 가장 가까운 K개 데이터의 범주를 비교해 다수결로 분류합니다.

d = √((x₁ − x₂)² + (y₁ − y₂)²)

어려움 단계에서는 모든 학습 데이터의 거리 계산 결과와 범주별 투표 수를 확인합니다. 데이터 수가 늘어날수록 비교해야 할 거리가 많아지는 이유도 확인할 수 있습니다.

주의: 실제 붓꽃 데이터 등은 교육용으로 특징 범위를 단순화한 예시입니다. KNN은 특징의 단위와 범위에 영향을 받으므로 실제 분석에서는 표준화·정규화가 중요합니다. 주택 가격대 예시도 실제 부동산 가격 예측 모델이 아니라 분류 원리 시연용입니다.

인공신경망에서 꼭 알아야 할 개념

입력층: 원본 데이터를 수치로 바꿔 신경망에 전달합니다. 실제 메일 분류에서는 문장 임베딩, URL 특징, 발신 도메인 정보 등 훨씬 많은 입력 특징을 사용할 수 있습니다.

가중치(weight): 각 입력이 다음 뉴런의 계산에 미치는 영향입니다. 학습 과정에서 조정되는 핵심 매개변수입니다.

편향(bias): 가중합에 더하는 값으로, 뉴런이 활성화되는 기준을 이동시킵니다.

가중합과 활성화 함수: z=Σ(wx)+b를 계산한 뒤 시그모이드 σ(z)=1/(1+e⁻ᶻ)를 적용합니다. 시그모이드는 값을 0~1 사이로 변환합니다.

순전파: 입력층에서 은닉층, 출력층 방향으로 계산이 진행됩니다. 각 은닉 뉴런은 입력 특징을 서로 다른 비율로 조합해 패턴을 표현합니다.

손실 함수: 예측값과 정답의 차이를 수치화합니다. 이 실험에서는 L=½(y−t)²를 사용합니다.

역전파: 출력층의 오차가 각 가중치에 미치는 영향을 연쇄법칙으로 거꾸로 계산합니다. 경사하강법은 손실이 줄어드는 방향으로 가중치를 갱신합니다.

현실과의 차이: 실제 스팸 탐지 모델은 훨씬 많은 데이터와 특징, 여러 은닉층을 사용하고 훈련·검증·테스트 데이터를 나눠 성능을 평가합니다. 여기의 3–4–1 구조와 가중치는 원리 이해를 위한 축소 모델입니다. 출력값도 실제 서비스의 정확한 스팸 확률을 뜻하지 않습니다.
